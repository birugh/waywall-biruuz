# Remaps

Dokumen ini dibuat otomatis dari `remaps.lua` oleh `scripts/gen-docs.lua`. Edit sumbernya, bukan file ini.

## crafts: ow, wo, got

Menukar A dan O untuk craft ow, wo, dan got.

| Tombol | Jadi |
| --- | --- |
| `A` | `O` |
| `O` | `L` |

## move to root in piechart

Tombol grave dan 0 saling bertukar untuk pindah ke root di piechart.

| Tombol | Jadi |
| --- | --- |
| `grave` | `0` |
| `0` | `grave` |

## remove word

Tombol 2 dan backspace saling bertukar untuk menghapus satu kata.

| Tombol | Jadi |
| --- | --- |
| `2` | `8` |
| `backspace` | `2` |

## to easily open piechart, also without crouching

RIGHTSHIFT dan MOUSE4 saling bertukar supaya piechart mudah dibuka, juga tanpa crouch.
