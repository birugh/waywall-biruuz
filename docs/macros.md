# MACROS

Dokumen ini dibuat otomatis dari `config/macros.lua` oleh `scripts/gen-docs.lua`. Edit sumbernya, bukan file ini.

## resolution changes

Macro ganti resolusi layar: thin, wide, dan tall.

| Aksi | Tombol |
| --- | --- |
| `thin` | `Shift-F5` |
| `wide` | `Shift-F6` |
| `tall` | `Shift-F7` |

## startup actions

Aksi yang jalan saat startup: toggle fullscreen dan buka Paceman.

| Aksi | Tombol |
| --- | --- |
| `toggle_fullscreen_key` | `Shift-O` |
| `launch_paceman_key` | `Shift-F10` |

## during game actions

Aksi saat main: toggle Ninjabrain Bot dan toggle remaps.

| Aksi | Tombol |
| --- | --- |
| `toggle_ninbot_key` | `Shift-F8` |
| `toggle_remaps_key` | `Shift-F9` |
